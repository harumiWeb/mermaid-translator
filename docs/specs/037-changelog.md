# Spec: Changelog

## ID

037-changelog

## Goal

Provide a `CHANGELOG.md` at the repository root that summarizes notable changes
using Git tags as release boundaries.

## In Scope

- Create `CHANGELOG.md` at the repo root
- Use Git tags as the primary release separators
- Summarize changes based on release/tag history

## Out of Scope

- Creating or modifying Git tags
- Establishing semantic versioning rules
- Generating release notes beyond the repository history

## Done When

- `CHANGELOG.md` exists at the repo root
- Sections are organized by tag
- Entries reflect notable changes from release history
