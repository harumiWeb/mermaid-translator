# 実装タスク

このドキュメントでは、`docs/specs/` 配下の仕様から厳密に派生した、具体的な実装レベルのタスクを定義します。

すべての実装作業は、ここで定義されたタスクに基づいて行う必要があります。

---

## このドキュメントの使い方

- タスクは、コードを記述する **前** に作成する必要があります。
- 各タスクは、1 つ以上の仕様 ID を参照する必要があります。
- タスクは、**どのように実装するか** ではなく、**何を実装するか** を記述します。
- タスクが既存の仕様から派生しない場合:
- 停止し、新しい仕様または改訂された仕様を提案してください。

---

## 記述ルール

- 未完了は[ ], 完了は[x]で記述
- 抽象的なタスクは禁止、具体的タスクをネストを活用しながら定義する

### タスクステータスの凡例

- [ ] 未開始
- [~] 進行中
- [x] 完了
- [!] ブロック済み (仕様の明確化が必要)
