# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it using
one of the following methods:

- Email: momocchi0415@gmail.com
- GitHub Issues: create a new issue with the `security` label

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigations (if known)

We aim to acknowledge reports within 3 business days and provide a status update
within 10 business days. Timelines may vary depending on severity and scope.

## Supported Versions

Security fixes are provided for the latest released version only.
