# Mermaid Translator

## Short Description

> **Mermaid Translator lets you instantly preview Mermaid code found on any web page, even if the site doesn't support Mermaid.**

---

## Description

Mermaid Translator lets you **render Mermaid diagrams from selected text on any web page**.
It works great with Mermaid snippets generated by AI chat services, as well as Mermaid code embedded in internal docs, wikis, or technical articles.
No setup, no page-specific rules. Just select text and click.

---

### 🍰 Key Features

- **Instant preview for AI‑generated Mermaid code**
  View Mermaid diagrams directly from AI responses on the same page.
- **Works on non‑Mermaid sites**
  Internal portals, custom web apps, and non‑Markdown pages are supported.
- **Shadow DOM for stable rendering**
  Renders in an isolated overlay to avoid breaking complex UIs.
- **Pan and zoom support**
  Easily inspect large or dense diagrams.
- **Export as PNG / SVG**
  Save rendered diagrams for docs and presentations.
- **Themes and dark mode**
  Switch Mermaid themes to match your environment.

---

### 🖱 How to Use

1. Select Mermaid text on a web page
2. A small action button appears near your selection
3. Click the button to render the diagram

**Nothing runs automatically.**
You always stay in control.

---

### 🌐 Works Everywhere

- Technical blogs and documentation
- GitHub Issues / README
- Internal tools and company wikis
- Pages with unusual HTML structures

No dependency on Markdown blocks, tags, or specific sites.

---

### 🍰 Unobtrusive by Design

- No auto rendering
- No layout changes
- No focus or scroll hijacking
- No persistent UI

If rendering fails, it quietly does nothing.

---

### 🔒 Privacy & Security

- No external network requests
- No data collection
- No analytics
- All processing happens locally in your browser
