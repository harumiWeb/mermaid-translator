# Mermaid Translator

## Short Description

> **Mermaid Translator 可让你在任何网页上从选中的 Mermaid 代码即时预览图表，即使该网站不支持 Mermaid。**

---

## Description

该扩展可在任意网页上 **直接从选中文本渲染 Mermaid 图表**。
无论是 ChatGPT / Claude 等 AI 服务生成的 Mermaid 代码，还是内网文档、Wiki、技术文章中的 Mermaid，都可以在原页面即时查看。
无需设置，不依赖页面结构，只需选中文本并点击即可。

> ※ ChatGPT 和 Claude 为 OpenAI / Anthropic 的商标。本扩展与其无关。

---

### 🍰 主要功能

- **AI 生成 Mermaid 即时预览**
  直接在页面上查看 AI 输出的 Mermaid 图表。
- **非 Mermaid 网站也可用**
  内部门户、定制 Web 应用、非 Markdown 页面均可渲染。
- **Shadow DOM 稳定渲染**
  采用隔离式覆盖层，复杂 UI 也不易被破坏。
- **支持平移与缩放**
  便于查看大型或复杂图表。
- **导出 PNG / SVG**
  将渲染结果保存并用于文档或演示。
- **主题与深色模式**
  可切换 Mermaid 主题以适配环境。

---

### 🖱 使用方法

1. 在网页上选中 Mermaid 文本
2. 选区附近出现小按钮
3. 点击按钮即可渲染图表

**不会自动执行任何操作。**
始终由你掌控。

---

### 🌐 适用于任何网站

- 技术博客与文档
- GitHub Issues / README
- 内部工具与公司 Wiki
- HTML 结构特殊的网页

不依赖 Markdown 代码块或特定标签。
