Mermaid Translator

简短说明:
Mermaid Translator 可以在不支持 Mermaid 的网页上，直接预览你选中的 Mermaid 代码图表。

说明:
在网页中选中 Mermaid 语法文本即可渲染成图表。
适用于 AI 聊天服务生成的 Mermaid 代码，以及内部文档、Wiki、技术文章中的 Mermaid 片段。
无需设置，选中并点击即可。

主要功能:

1. 即时预览 AI 生成的 Mermaid 代码。
2. 在不支持 Mermaid 的站点也可使用，如内部系统、自定义 Web 应用、非 Markdown 页面。
3. 使用 Shadow DOM，显示稳定，不破坏页面样式。
4. 支持拖拽与缩放，便于查看大型图表。
5. 支持导出 PNG 或 SVG。
6. 支持 Mermaid 主题与暗色模式。

使用方法:

1. 选中网页中的 Mermaid 文本。
2. 选区附近会出现一个小按钮。
3. 点击按钮即可渲染图表。

不会自动执行任何操作，始终由用户掌控。

适用于各种页面:
技术博客与文档、GitHub Issue 与 README、内部工具与 Wiki、HTML 结构特殊的页面。
不依赖 Markdown 代码块或特定标签。

不打扰页面:
不自动渲染，不修改布局，不劫持焦点或滚动，不常驻 UI。
渲染失败时会静默不打扰。

隐私与安全:
无外部网络请求、无数据收集、无分析。所有处理均在本地浏览器内完成。
