# Mermaid Translator

## Short Description

> **在任意网页中从选中文本即时渲染 Mermaid 图表。**

---

## Description

### ✨ 这个扩展能做什么

该扩展可让你在任何网页上 **直接从选中的 Mermaid 文本渲染图表**。

无需设置。
不依赖页面结构。
选中并点击即可。

- 从选中文本渲染 Mermaid 图表
- 编辑模式：打开更大的面板，修改代码并即时预览

---

### 🖱️ 使用方式

1. 在网页上选中 Mermaid 文本
2. 选择附近会出现一个小按钮
3. 点击按钮即可立即渲染图表

不会自动执行任何操作 — **始终由你掌控**。

---

### 🌐 任意网站可用

- 博客和文档
- GitHub Issues 与 README
- 内部工具与公司 Wiki
- 结构特殊的网页

本扩展 **不依赖** Markdown 代码块或特定标签。
