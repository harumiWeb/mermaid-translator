# Mermaid Translator

## ショート説明

> **Web ページ上で選択した Mermaid 記法を、その場で図としてレンダリングできます。**

---

## 説明文（本文）

### ✨ この拡張機能でできること

- 選択したテキストから Mermaid ダイアグラムをレンダリング
- 編集モード：より大きなパネルを開き、Mermaid コードを調整し、変更内容をプレビューします

この拡張機能は、**Web ページ上で選択した Mermaid 記法のテキストを、即座に図として表示**します。

特別な設定は不要です。
ページ構造に依存しません。
テキストを選択して、クリックするだけです。

---

### 🖱️ 使い方

1. Web ページ上の Mermaid 記法テキストを選択します
2. 選択範囲の近くに小さなアクションボタンが表示されます
3. ボタンをクリックすると、図がその場に表示されます

**自動で何かが実行されることはありません。**
操作の主導権は常にユーザー側にあります。

---

### 🌐 どこでも使えます

- 技術ブログ・ドキュメント
- GitHub の Issue / README
- 社内ツール・社内 Wiki
- HTML 構造が特殊なページ

Markdown のコードブロックや特定のタグに依存せず、
**あらゆる Web ページで動作**します。

---

### 🧘 ページの邪魔をしない設計

- 自動レンダリングは行いません
- ページのレイアウトを変更しません
- フォーカスやスクロールを奪いません
- 常駐 UI は表示しません

もし処理に失敗した場合でも、
**何も起こらないだけ**です。

---

### 🔒 プライバシーと安全性

- 外部サーバーとの通信は行いません
- 個人情報やページ内容の収集は行いません
- 解析・処理はすべてローカル（ブラウザ内）で完結します
