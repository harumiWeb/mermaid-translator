# Mermaid Translator

## ショート説明

> **Mermaid Translator は、AI チャットや Mermaid 非対応の Web ページに表示された Mermaid コードを、その場で図として確認できる Chrome 拡張機能です。**

---

## 説明文

この拡張機能は、**Web ページ上で選択した Mermaid 記法のテキストを、即座に図として表示**します。

AI チャットサービス などが生成した Mermaid コードや、
社内ドキュメント・Wiki・技術記事に埋め込まれた Mermaid 記法を、
ページを離れることなく即座にレンダリングできます。

特別な設定は不要です。
ページ構造に依存しません。
テキストを選択して、クリックするだけです。

---

### 🧜 主な特徴

- **AI が生成した Mermaid コードを即プレビュー**
  AI チャットの回答内に含まれる Mermaid 記法を、その場で図として確認できます。

- **Mermaid 非対応サイトでも動作**
  社内ポータル、独自 Web アプリ、Markdown 未対応サイトなどでもレンダリング可能。

- **Shadow DOM 対応の安定した表示**
  ChatGPT や複雑な Web UI でも壊れにくいオーバーレイ表示方式を採用。

- **パン・ズーム操作対応**
  大きな図や複雑な構成でも快適に閲覧できます。

- **PNG / SVG エクスポート対応**
  レンダリングした図をそのまま資料やドキュメントに利用可能。

- **Mermaid テーマ切替・ダークモード対応**
  閲覧環境に合わせて見やすく表示。

---

### 🖱️ 使い方

1. Web ページ上の Mermaid 記法テキストを選択します
2. 選択範囲の近くに小さなアクションボタンが表示されます
3. ボタンをクリックすると、図がその場に表示されます

**自動で何かが実行されることはありません。**
操作の主導権は常にユーザー側にあります。

---

### 🌐 どこでも使えます

- 技術ブログ・ドキュメント
- GitHub の Issue / README
- 社内ツール・社内 Wiki
- HTML 構造が特殊なページ

Markdown のコードブロックや特定のタグに依存せず、
**あらゆる Web ページで動作**します。

---

### 🧘 ページの邪魔をしない設計

- 自動レンダリングは行いません
- ページのレイアウトを変更しません
- フォーカスやスクロールを奪いません
- 常駐 UI は表示しません

もし処理に失敗した場合でも、
**何も起こらないだけ**です。

---

### 🔒 プライバシーと安全性

- 外部サーバーとの通信は行いません
- 個人情報やページ内容の収集は行いません
- 解析・処理はすべてローカル（ブラウザ内）で完結します
