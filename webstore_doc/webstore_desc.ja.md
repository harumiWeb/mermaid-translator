Mermaid Translator

短い説明:
Mermaid Translator は、Mermaid 非対応の Web ページでも、選択した Mermaid コードをその場で図として確認できる Chrome 拡張機能です。

説明:
Web ページ上で選択した Mermaid 記法テキストを、即座に図として表示します。
AI チャットサービスが生成した Mermaid コードや、社内ドキュメントや技術記事に埋め込まれた Mermaid 記法にも対応します。
特別な設定は不要で、テキストを選択してクリックするだけです。

主な特徴:

1. AI が生成した Mermaid コードを即プレビューできます。
2. Mermaid 非対応サイトでも動作します。社内ポータル、独自 Web アプリ、Markdown 非対応ページでも利用できます。
3. Shadow DOM により、複雑な UI でも表示が崩れにくい構成です。
4. パンとズーム操作で大きな図も閲覧しやすいです。
5. PNG と SVG にエクスポートできます。
6. Mermaid テーマとダークモードに対応します。

使い方:

1. Web ページ上の Mermaid 記法テキストを選択します。
2. 選択範囲の近くに小さなアクションボタンが表示されます。
3. ボタンをクリックすると図が表示されます。

自動で何かが実行されることはありません。操作の主導権はユーザー側にあります。

どこでも使えます:
技術ブログ、ドキュメント、GitHub の Issue や README、社内ツールや社内 Wiki、特殊な HTML 構造のページでも動作します。
Markdown のコードブロックや特定タグに依存しません。

ページの邪魔をしません:
自動レンダリングは行いません。レイアウト変更やフォーカス、スクロールの奪取は行いません。常駐 UI は表示しません。
レンダリングに失敗しても静かに何もしません。

プライバシーと安全性:
外部通信やデータ収集、解析は行いません。処理はすべてローカルのブラウザ内で完結します。
