# Mermaid Translator

## Short Description

> **Mermaid Translator는 Mermaid를 지원하지 않는 웹페이지에서도 선택한 Mermaid 코드를 즉시 다이어그램으로 보여주는 Chrome 확장입니다.**

---

## Description

이 확장은 **웹페이지에서 선택한 Mermaid 텍스트를 바로 다이어그램으로 렌더링**합니다.
AI 채팅 서비스가 생성한 Mermaid 코드나 사내 문서, 위키, 기술 문서에 포함된 Mermaid를 페이지를 떠나지 않고 즉시 확인할 수 있습니다.
별도 설정 없이, 페이지 구조에 의존하지 않습니다. 텍스트를 선택하고 클릭만 하면 됩니다.

---

### 🍰 주요 기능

- **AI가 생성한 Mermaid 코드 즉시 미리보기**
  AI 응답에 포함된 Mermaid를 그 자리에서 확인할 수 있습니다.
- **Mermaid 미지원 사이트에서도 동작**
  사내 포털, 커스텀 웹앱, Markdown 미지원 사이트에서도 렌더링됩니다.
- **Shadow DOM 기반 안정적 표시**
  복잡한 UI에서도 깨지지 않는 오버레이 렌더링.
- **팬/줌 지원**
  큰 다이어그램도 편하게 탐색할 수 있습니다.
- **PNG / SVG 내보내기**
  렌더링한 그림을 문서에 바로 활용 가능.
- **테마/다크 모드 지원**
  환경에 맞게 보기 편한 테마로 전환.

---

### 🖱 사용 방법

1. 웹페이지에서 Mermaid 텍스트를 선택
2. 선택 근처에 작은 액션 버튼 표시
3. 버튼 클릭 시 즉시 다이어그램 표시

**자동으로 실행되는 동작은 없습니다.**
항상 사용자가 제어합니다.
