Mermaid Translator

짧은 설명:
Mermaid Translator는 Mermaid를 지원하지 않는 웹 페이지에서도 선택한 Mermaid 코드를 즉시 다이어그램으로 확인할 수 있는 Chrome 확장입니다.

설명:
웹 페이지에서 선택한 Mermaid 문법 텍스트를 즉시 다이어그램으로 렌더링합니다.
AI 채팅 서비스가 생성한 Mermaid 코드나 사내 문서, 기술 문서에 포함된 Mermaid 코드에도 잘 동작합니다.
설정 없이 텍스트를 선택하고 클릭하면 됩니다.

주요 기능:

1. AI가 생성한 Mermaid 코드를 즉시 미리보기할 수 있습니다.
2. Mermaid 비지원 사이트에서도 동작합니다. 사내 포털, 커스텀 웹 앱, Markdown 비지원 페이지에서 사용 가능합니다.
3. Shadow DOM으로 복잡한 UI에서도 안정적으로 표시됩니다.
4. 팬/줌으로 큰 다이어그램도 쉽게 확인할 수 있습니다.
5. PNG와 SVG로 내보내기 가능합니다.
6. Mermaid 테마와 다크 모드를 지원합니다.

사용 방법:

1. 웹 페이지에서 Mermaid 텍스트를 선택합니다.
2. 선택 영역 근처에 작은 액션 버튼이 나타납니다.
3. 버튼을 클릭하면 다이어그램이 표시됩니다.

자동 실행은 없습니다. 사용자가 항상 제어합니다.

어디서나 동작:
기술 블로그와 문서, GitHub 이슈와 README, 사내 도구와 위키, 특이한 HTML 구조의 페이지에서도 동작합니다.
Markdown 코드 블록이나 특정 태그에 의존하지 않습니다.

방해하지 않는 설계:
자동 렌더링 없음, 레이아웃 변경 없음, 포커스/스크롤 가로채기 없음, 상시 UI 없음.
렌더링에 실패해도 조용히 아무것도 하지 않습니다.

개인정보와 보안:
외부 통신, 데이터 수집, 분석 없음. 모든 처리는 로컬 브라우저에서 수행됩니다.
