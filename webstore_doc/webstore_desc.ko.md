# Mermaid Translator

## Short Description

> **모든 웹 페이지에서 선택한 Mermaid 텍스트를 즉시 다이어그램으로 렌더링합니다.**

---

## Description

### ✨ 이 확장 프로그램이 하는 일

이 확장 프로그램은 어떤 웹 페이지에서든 **선택한 Mermaid 텍스트를 바로 다이어그램으로 렌더링**할 수 있게 해줍니다.

설정 불필요.
페이지 구조에 의존하지 않음.
선택하고 클릭하기만 하면 됩니다.

- 선택한 텍스트에서 Mermaid 다이어그램 렌더링
- 편집 모드: 더 큰 패널을 열어 코드 수정 후 즉시 미리보기

---

### 🖱️ 사용 방법

1. 웹 페이지에서 Mermaid 텍스트를 선택합니다
2. 선택 영역 근처에 작은 버튼이 나타납니다
3. 버튼을 클릭하면 즉시 다이어그램이 렌더링됩니다

자동으로 실행되는 일은 없습니다 — **항상 사용자가 제어합니다**.

---

### 🌐 어디서든 사용 가능

- 블로그 및 문서
- GitHub 이슈와 README
- 사내 도구 및 위키
- 구조가 특이한 웹 페이지

이 확장 프로그램은 Markdown 블록이나 특정 태그에 **의존하지 않습니다**.
