# Mermaid Translator

## Short Description

> **Render Mermaid diagrams instantly from selected text on any web page.**

---

## Description

### ✨ What this extension does

This extension lets you **render Mermaid diagrams directly from selected text** on any web page.

No setup.
No page-specific rules.
Just select Mermaid text and click.

- Render Mermaid diagrams from selected text
- Edit mode: open a larger panel, tweak Mermaid code, and preview changes

---

### 🖱️ How it works

1. Select Mermaid text on a web page
2. A small action button appears near your selection
3. Click the button to render the diagram instantly

Nothing happens automatically — **you are always in control**.

---

### 🌐 Works anywhere

- Blogs and documentation
- GitHub Issues and README pages
- Internal tools and company wikis
- Any website, regardless of structure

This extension does **not** rely on Markdown blocks, specific tags, or domains.

---

### 🧘 Designed to be unobtrusive

- No automatic rendering
- No page layout changes
- No focus stealing
- No persistent UI

If something fails, it simply does nothing.

---

### 🔒 Privacy & Security

- No external network requests
- No data collection
- No analytics
- All processing happens locally in your browser
